근본 원인(판정, 신뢰도 높음 ≈ 85–90 %): X 오차의 위치 의존 성분 θx(∂X/∂Y ≈ 5.18 µrad)는 X 라인스캔 순간에 웨이퍼(시료) 전체가 미소 회전하기 때문에 생깁니다. 이 회전은 시료측 XY 스캐너의 Y 오프셋에 비례합니다(κ = -0.192 ± 0.034 µrad/µm, 95 % CI). 레시피는 X 라인을 정렬 기준점에서 Y로 −25 µm(+기준스캔 보정 −2.7 µm) 떨어진 곳에 두므로, X 측정 순간 스캐너 Y ≈ -28.0 µm → 회전 ≈ 5.4 µrad → Y = ±120 mm 다이가 X로 ±0.64 µm 이동 → X Range ≈ 1.3 µm로 spec(1.0 µm) 초과. Y 라인은 스캐너 Y ≈ −0.8 µm에서 측정하므로 회전이 거의 없어 Y는 통과합니다.

어디서 생기나: 시료측 XY 스캐너/척 조립체(스캐너 Y 구동 시 기생 회전·yaw). 카메라 정렬은 스캐너 오프셋 적용 전에 끝나고, 스캐너 센서는 병진만 재므로(지령값과 2 nm 이내 일치) 어느 쪽도 이 회전을 보지 못합니다. 물리적 부품(플렉셔 기생 yaw vs 척/θ 스테이지 컴플라이언스)은 미확정 — 신뢰도 중간 ≈ 60 %

4. 이미지 분석 결과

4-1. 측정 방법 (요약)

  • 패턴 위치·회전: 기준 다이 영상의 패턴 영역(정렬 영상 640×640 px, 착지 영상은 팁과 겹치지 않는 하부 660×470 px)을 템플릿으로, 정규상관으로 초기 위치 → ECC(강도 정규화, 조명 변화에 강건) 서브픽셀 정합(평행이동, 강체, 아핀). 정렬 영상 패턴 위치는 로그 Fine Match와 상관 r ≈ 0.8(개발용 1개 로트 확인; 정렬 영상 일부에 롤링셔터성 왜곡 확인).
  • 캔틸레버 그림자(정렬 영상): 상단 0~330행 × 40~1560열 띠를 가우시안(σ=3 px) 처리 후 같은 로트 Die2 기준 및 전역 기준과 ECC 평행이동 정합 → dx, dy.
  • 착지 영상: 파일 기록 시각으로 확인한 결과 X/Y 라인스캔 시작 직전(스캔 파라미터 설정 직후) 촬영. 팁이 시료에 접근해 캔틸레버와 패턴이 함께 보임 → 캔틸레버(280×360 px 영역)와 패턴을 각각 정합하여 팁 이동과 시료 이동을 분리.
  • 모든 값은 로트 내 편차로 변환 후 다이 X/Y에 회귀, 로트 군집 표준오차 사용(2,980 다이, 149 로트).

4-2. 핵심 시험: 캔틸레버 그림자가 스테이지 Y에 비례해 움직이는가? (H1)

결과: 그림자 X 기울기 = -0.97 ± 0.09 µrad(로트 기준, 팁 이동 환산) / 전역 기준 -1.09 ± 0.03 µrad. H1이 참이라면 +5.18 µrad(±120 mm에서 ±0.62 µm, 약 ±1.8 px)여야 하나, 측정값은 부호가 반대이고 크기는 19 % 수준 → H1 반박.
감도 확인(양성 대조): 같은 그림자 측정이 로트 시작 과도 현상에서 Die1 +0.64 µm, Die2 +0.40 µm의 팁 이동을 검출했고, 이는 착지 영상의 캔틸레버 이동(Die1 +0.55, Die2 +0.29 µm)과 AFM 잔차(+0.62, +0.25 µm)와 일치합니다. 즉 이 방법은 0.3 µm 이상의 팁 이동을 볼 수 있으며, θx에 해당하는 이동(±0.6 µm)은 없었습니다.
정밀도: 같은 위치 연속 측정(Die2−Die1) 차이의 표준편차: 그림자 0.149 µm, 착지 캔틸레버 0.035 µm, 착지 패턴 0.054 µm. 다이별 회귀 잔차 그림자 0.115 µm. 기울기 추정 SE 0.044 µrad로 H1 크기(5.2)의 1 % 이하.

4-3. 착지 영상: 팁이 움직였나, 시료가 움직였나?

  • 착지 영상의 팁−패턴 X 거리는 AFM HZ1_O X와 r = -0.9993, 잔차 12 nm로 일치 → 카메라가 착지 오차를 직접 보고 있음(환산계수 2.60 px/µm, 공칭 2.92 px/µm와 11 % 차이: 미해결 스케일 차).
  • θx 분해: 패턴(시료) 이동 4.90 ± 0.03 µrad, 캔틸레버(팁) 이동 0.28 ± 0.02 µrad → θx의 95 %가 시료 쪽.
  • 같은 영상에서 패턴 Y 이동은 다이 X에 비례(5.13 ± 0.03 µrad, 카메라 공칭 스케일). 시료 좌표로 바꾸면 dX ∝ −ω·Y, dY ∝ +ω·X 형태의 반대칭장 = 강체 회전(ω ≈ 4.4~5.1 µrad).
  • Y 라인스캔 시작 영상(스캐너 Y ≈ −10.8 µm)에서는 패턴 X 기울기 0.76 µrad로 대부분 사라짐 → 이동은 X 측정 시점(스캐너 Y ≈ −28 µm)에 특유.
  • 정렬 영상(스캐너 오프셋 적용 전)의 패턴 X 기울기 0.63 ± 0.15 µrad, 로그 Fine Move X -1.19 µrad → 정렬 시점에는 회전 없음.

4-4. 패턴 각도(스테이지 yaw)

영상 내 패턴 회전각(착지 영상, 영상당 정밀도 ≈ 43 µrad)은 다이 X에 따라 0.58 µrad/mm(±120 mm에서 약 140 µrad) 변하고(정렬 영상 0.54 µrad/mm로 재현), Y에 따라서는 0.16 µrad/mm(정렬 영상 −0.08 ± 0.17)입니다. 즉 X축 이동에 따른 스테이지 yaw는 실재하지만, 정렬점과 측정점 거리(≤ 75 µm) × 140 µrad ≈ 10 nm로 θx와 무관합니다. ω ≈ 5 µrad 회전 자체는 영상 각도 정밀도(≈ 43 µrad)보다 작아 영상 각도로는 직접 보이지 않으며, 다이 위치 변위의 반대칭장으로만 검출됩니다.

4-5. AFM 원시 TIFF

Park TIFF 태그(50434 데이터, 50435 헤더)를 직접 해독: 모든 라인은 1차원(4096점, 20 µm, 2D 영상 아님) → 엣지 각도는 AFM에서 측정 불가. 원시 Height에서 재계산한 X 엣지 위치는 HZ1_O X와 r = 0.99997, 차이 표준편차 3.4 nm(3,278 라인; 이상치 4개는 1111 로트 Die13 이중 엣지). 스캐너 X 검출기 평균 − 지령 = −2.08 ± 0.12 nm, X라인 중 Y 검출기 = 지령 −0.17 nm(잡음 0.30 nm), 모든 검출기 값이 스테이지 위치와 무관 → 스캐너는 병진으로는 지령대로 움직였고, 엣지 검출 알고리즘·라인 데이터 오류도 아님. 헤더 각도(angle)=0, head rotation=0, 캔틸레버 AC160TS 전 로트 동일.

4-6. 팁 영상·공진

팁 영상 150장: 정합 상관 1.0(형상 동일), 영상 위치는 로그 Tip Fine Match와 r = 0.994, 팁 교체 흔적 없음. 공진 337.48 ± 0.01 kHz, Q ≈ 480 → 팁 상태 변화 없음. 기준스캔 X 결과는 11-06 → 11-09 동안 +0.0155 µm/h(r = 0.98) 서서히 증가하고 팁 영상 위치 X도 함께 이동(r = 0.95) → 카메라↔팁의 느린 열적 드리프트이며 로트마다 기준스캔이 정상 보정(θx와 상관 r = −0.30, 무관).

6. 근본 원인 판단과 메커니즘

  1. 정렬: 스테이지가 다이로 이동 → Coarse/Fine 패턴 정렬(카메라). 이때 시료 XY 스캐너 오프셋은 0 근처 → 회전 없음, 비전은 정상(θx 없음).
  2. 보정 적용: Fine 잔차와 기준스캔 보정은 스테이지가 아니라 시료 XY 스캐너 오프셋으로 적용. X 라인은 레시피상 Y −25 µm(+기준스캔 Y −2.7 µm) 위치 → 스캐너가 웨이퍼 척을 Y로 ≈ -28.0 µm 이동.
  3. 기생 회전: 이 Y 구동이 웨이퍼를 회전 중심(척 중심 부근, 추정 Y₀ ≈ +14 mm, 병진 크로스토크 없다고 가정한 유도값) 둘레로 ω = κ·offY ≈ 5.4 µrad 회전. 스캐너 센서는 병진만 측정하므로 지령값과 일치(2 nm)하게 보임.
  4. 결과: 다이 X 변위 = −ω·(Y − Y₀) → Y = ±120 mm에서 ∓/± 0.64 µm. 착지 영상에서도 패턴(시료)만 이동, 팁은 고정. AFM HZ1_O X = θx·Y, θx = 5.18 µrad.
  5. Y가 통과하는 이유: Y 라인은 스캐너 Y ≈ −0.8 µm에서 측정 → 회전 ≈ 0.15 µrad → ∂Y/∂X ≈ 0.1 µrad. (X 오프셋 +30 µm에서의 회전은 AFM Y 데이터상 거의 없음 — X축 구동의 기생 회전은 작거나 비선형)

왜 여러 대책 시험에서 θx가 그대로였나: Surface Map·Stage Cal·Align offset·측정 순서·View Panning 블록은 모두 스테이지/비전 측 요소이고, X 라인의 스캐너 Y오프셋(−25 µm)과 스캐너/척 회전 특성은 바꾸지 않았기 때문.

6-1. 인과 검증: 같은 다이에서 스캐너 Y오프셋이 클수록 X 오차가 커지는가?

Fine 보정량은 다이마다 무작위로 ±0.4 µm 변하므로 X 라인의 실제 스캐너 Y오프셋도 다이·로트마다 조금씩 다릅니다(자연 실험). 사이트·로트 고정효과를 제거하고 HZ1_O X를 (다이 Y × 오프셋 편차)에 회귀하면 κ = -0.192 ± 0.034 µrad/µm(로트 내 성분 −0.194, 로트 간 성분 −0.182로 일치). 카메라 착지 영상으로도 독립적으로 -0.208(t = 11.0). 회전 계수 하나와 오프셋 평균으로 θx 크기를 4 % 이내로 재현합니다(예측 5.37, 실측 5.18).

점: 20개 사이트 각각에서 140 로트에 걸친 dHZ1_O X/d(Y오프셋) (같은 Y의 사이트는 X에 따라 좌우로 약간 벌려 표시). 점선: 전체 회귀 κ·Y. 사이트별 값은 잡음이 크며(시간 추세 등 교란 포함), 결론은 2원 고정효과 회귀(t = -11.2)에 근거.

6-2. spec 판정 재현

원 데이터: X Range 1.32 µm (로트별 1.21~1.42), PASS 0/149. 각 다이에서 κ·offY·Y만 빼면(로트별 적합 없음) Range 0.36 µm (0.22~0.59), StdDev 0.077 µm, PASS 149/149. Die2/Die3 과도분까지 빼면 Range 0.21 µm. Y는 146/149 PASS(실패 3로트 = Align 0° 2로트와 Reverse 1로트: StdDev 0.26 µm 수준의 팁 측 Y 드리프트, Sample191은 Die20 −8.0 µm 단발 이상치 포함).

6-3. 부수 현상: 로트 시작 과도(Die1/Die2)

Die1→Die3에서 X가 +0.62 → +0.25 → +0.10 µm로 감쇠(τ ≈ 60 s). one-die 시험(같은 다이 6회)도 510 → 291 → 188 → 154 → 139 → 134 nm(τ = 63 ± 2 s). 카메라상 주성분은 캔틸레버(팁) 이동이고 그림자에도 보임 → 로트 시작 시퀀스(팁 위치결정 위치 이동, Z 안전위치(15,000 µm, 약 7 mm) 상승·하강) 이후의 헤드 측 과도(열/기계 안정화)로 추정. 기준스캔이 이 과도 중(로트 시작 ≈ 70 s 후)에 측정되어 로트 X 평균을 치우치게 할 수 있으며, spec 계산에 포함되는 Die2(+0.25 µm)가 Range를 키웁니다. θx와는 독립(위치 무관, 시간 의존).

8. 한계와 미검증 사항

  • 부품 특정 미완: 회전이 스캐너 플렉셔 자체의 기생 yaw인지, 스캐너가 움직이는 척/θ축의 변형인지는 구분 불가 → T2/T3 필요.
  • 회전 중심: 직접 식별 불가. 병진 크로스토크가 없다는 가정에서 Y₀ ≈ +14 mm(웨이퍼 중심 부근)로 추정.
  • Y 라인 시점 불일치: Y스캔 시작 영상(스캐너 Y −10.8 µm)의 회전은 선형 모델 예측(≈2 µrad)보다 작은 0.76 µrad. X 오프셋 항(−0.04~−0.09 µrad/µm)을 넣으면 영상은 맞지만 AFM Y(∂Y/∂X ≈ 0.1 µrad)와는 맞지 않음 → 회전은 Y 구동에 대해 선형이 아니거나 이력(hysteresis)을 가짐. θx 결론(−28 µm 부근의 선형 계수와 크기)에는 영향 없음.
  • View Panning 4로트: θx 4.86 µrad로 모델 예측(≈5.7)보다 15 % 낮음 — 당시 계수가 달랐을 가능성(미해결).
  • 카메라 환산계수: 착지 영상 팁−패턴 vs HZ1_O 기울기 2.60 px/µm (공칭 548.4 µm/1600 px = 2.92 px/µm). 11 % 차이의 원인(카메라 배율 vs 스캐너 보정 vs 촬영 시점) 미확인. 영상 기반 µm 값은 이 경험계수로 환산(표기: HZ1_O 환산).
  • 그림자 미세 기울기: 그림자에 −0.97 µrad의 작은 Y 기울기(반대 부호)가 있음. 착지 캔틸레버(0.28)와 다르며, 배경 반사율/초점 차이에 의한 정합 편향 가능성 — 결론(H1 반박)에는 영향 없음.
