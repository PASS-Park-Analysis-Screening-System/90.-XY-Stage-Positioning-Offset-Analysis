# WI-XY Scanner-Rotation (초안) — XY 스캐너 회전 시험

| 항목 | 내용 |
|---|---|
| 문서 상태 | **초안** — 규격은 잠정값, 장비 데이터로 확정 예정 |
| 작성 | 2026-11-12 |
| 관련 문서 | WI-XY Scanner-01 "XY Non-linearity error" (servo OFF) |
| 분석 도구 | PASS · XY Stage Positioning Offset Analysis → Export 탭 → **스캐너 회전 시험 분석** |

---

## 1. 목적

샘플 XY 스캐너를 Y로 구동하면 스캐너가 웨이퍼(척)를 함께 돌린다.
조사 결과, 폐루프(servo ON)에서 남는 회전은 Y 구동 1 µm당 약 **0.19 µrad**였다.
레시피 스캐너 오프셋이 큰 장비에서는 이 회전이 XY Stage Positioning 시험의 Range를 키운다.
예를 들어 −25 µm 오프셋 런에서는 X Range가 약 1.45 µm로 FAIL이었다.

이 시험은 스캐너 회전을 하나의 값으로 잰다.

- **κ (µrad/µm)**: 스캐너 구동 1 µm당 회전량.

κ를 관리 항목으로 삼아, 출하 전과 스캐너 정비 후에 회전이 허용 범위 안에 있는지 확인한다.

## 2. 적용 모델

- All models w/ XY Scanner (샘플 XY 스캐너가 달린 모든 모델)

## 3. 관리 시점

| 시점 | 목적 |
|---|---|
| **출하 검사 (Final Test)** | 출하 전 κ를 기록하고 판정한다 |
| **스캐너 교체·선형화 후** | 스캐너 교체나 Linearization(WI-XY Scanner-01) 후 회전 상태를 확인한다 |

다른 시점(이상 조사 등)에 시험하면 분석 창에서 시험 단계를 "기타"로 고른다.

## 4. 선행 조건

1. **FOV 보정을 끝낸다.**
   - Vision 픽셀 크기(µm/px)를 확인한다.
   - 기본값은 0.34278 µm/px (FOV 836.378 µm / 2440 px)이다.
   - 값이 다르면 분석 창에 그 값을 넣는다.
2. **Metrocal 샘플을 로딩한다.**
   - 정렬 패턴(Vision 등록 패턴)이 Die 좌표 X ±120 mm(웨이퍼 중심 기준)의 Die에 있어야 한다.
   - 대조 시험을 하면 Die 좌표 Y ±120 mm의 Die에도 있어야 한다.
3. **XY 스캐너 Linearization이 끝난 상태여야 한다.** (WI-XY Scanner-01 After 확인 완료)
4. **servo ON (closed loop)으로 둔다.** Non-linearity 시험은 servo OFF다 — 5장의 두 가지 차이 중 하나다.
5. 장비가 충분히 안정된 상태여야 한다. 조건은 Positioning 시험과 같다.
6. 시험 중에는 스테이지(XY Stage)를 움직이지 않는다. 스캐너 오프셋만 바꾼다.

## 5. 시험 절차 (XEPi)

절차는 WI-XY Scanner-01과 같다 (offset stepping + Vision "GRAB and RUN").
Non-linearity 시험과 다른 점은 두 가지다.

- **servo ON** 상태에서 한다 (4장 4).
- 멀리 떨어진 **두 Die 지점**에서 각각 한 번씩 한다.

### 5.1 Y 스윕 — 본 시험

1. XEPi에서 XY Scanner가 servo ON(closed loop)인지 확인한다.
2. 스테이지를 **Die 좌표 X −120 mm의 Die (지점 A)**로 옮긴다.
   - 패턴을 화면 가운데에 맞춘다.
   - Vision 패턴은 WI-XY Scanner-01과 같은 방법으로 등록한다.
3. 스캐너 offset Y를 **−70 µm**로 둔다. X offset은 0으로 둔다.
4. 화면이 멈추면 **GRAB and RUN**을 누른다.
   - 로그에 `Match 1 : (x, y),Angle = …,Score = …` 가 **정확히 한 줄** 남았는지 확인한다 (5.3).
5. offset Y를 **+10 µm씩** 올리며 4를 되풀이한다. **+70 µm까지 15점**을 기록한다.
6. **드리프트 확인(권장)**: 이어서 offset을 **0 µm로 되돌려 한 번 더** GRAB and RUN 한다.
   - 시간이 되면 +70 → −70 µm로 되돌아오며 모두 재는 **왕복**(29점)이 더 좋다.
   - 같은 오프셋을 두 번 잰 변위 차가 0.2 µm를 넘으면 분석 창이 드리프트를 경고한다.
7. offset을 0으로 되돌리고 로그를 저장한다.
   - 파일 이름 예: `<장비번호>_RotY_A_<날짜>.txt`
8. 스테이지를 **Die 좌표 X +120 mm의 Die (지점 B)**로 옮겨 3~7을 되풀이한다. **두 지점의 오프셋 순서는 같게** 한다.
   - 파일 이름 예: `<장비번호>_RotY_B_<날짜>.txt`

### 5.2 X 스윕 — 대조 (선택)

- **Die 좌표 Y −120 mm**와 **Y +120 mm**의 Die에서 같은 방법으로 한다.
- 스캐너 offset X를 −70 → +70 µm (10 µm 간격)로 옮긴다. Y offset은 0으로 둔다.
- 결과는 참고값이며 판정에 쓰지 않는다. X 스윕만 분석하면 분석 창은 "참고"로 보이고 진단에 넣지 않는다.
  Y 구동만 회전을 일으키는지, X 구동도 회전을 일으키는지 구분하는 데 쓴다.
- 부호: X 스윕 κ는 (g_B − g_A) / (Y_B − Y_A) × 1000이다. 같은 반시계 회전이면 Y 스윕과 **부호가 반대**로 나온다.

### 5.3 주의 — 로그 한 줄 = 한 단계

- **GRAB and RUN 한 번에 `Match 1` 줄이 정확히 한 줄** 남아야 한다. 작업자가 단계마다 확인한다.
  - 한 번에 **여러 줄**이 남으면(같은 단계 반복 기록): 마지막 한 줄만 남기고 지운다.
  - **한 줄도 남지 않으면**: 다시 GRAB and RUN 한다. 그래도 없으면 그 자리에 `누락` 한 줄을 적는다.
  - XEPi 설정상 한 줄이 보장되지 않으면 줄마다 앞에 명령 값을 적는 형식(아래)을 쓴다.
- **다시 잰 단계(재시도)**: 대체된(먼저 잰) 줄을 **지운다**.
  - 또는 줄마다 앞에 명령 값을 탭으로 붙여 기록한다: `-30<탭>Match 1 : (…),Angle = …,Score = …`.
    이 형식이면 같은 명령의 줄이 두 번 있어도 그대로 계산한다.
  - 줄이 명령보다 많으면 분석 창은 **어느 줄이 맞는지 추측하지 않고** 남는 줄(같은 자리를 다시 잰 줄, 실패 줄)을 짚어 거절한다.
- **Score가 낮은 단계(0.8 미만)는 다시 GRAB and RUN 한다.**
  - 분석 창은 Score 0.8 미만 단계를 계산에서 빼고, 지점마다 최저 Score를 보인다 (기준은 설정 `rotation_test_gate`의 `score_min`).
  - 한 지점에서 뺀 단계는 다른 지점에서도 빼서 **두 지점을 같은 명령으로** 비교한다.
- 빈 줄과 `Match 2` 이상(같은 단계의 다른 후보)은 무시된다. `Match … fail`·`not found`가 적힌 줄과 `누락`·`-` 줄은 빠진 단계다.
- 소수점은 **마침표(.)**로 기록한다. 소수점 쉼표(`1369,01`)는 읽지 않고 오류로 알린다.
- **오프셋을 바꾼 뒤 화면이 멈춘 것을 보고 GRAB and RUN 한다.**
- **4개 검출기 값(X1, X2, Y1, Y2)도 함께 기록하기를 권장한다.** (11장 개정 제안 참고)

## 6. PASS 분석 창 입력

1. XY Stage Positioning Offset Analysis를 실행한다.
2. **Export** 탭에서 **스캐너 회전 시험 분석**을 연다. 별도 창이며, 메인 창과 함께 쓸 수 있다.
3. 다음을 입력한다.
   - **시험 단계**: 출하 검사 / 스캐너 교체·선형화 후 / 기타
   - **구동 축**: Y (본 시험)
   - **명령 목록**: `-70:70:10` (시작:끝:간격, 끝 포함). 쉼표 목록도 되고 이어 붙일 수 있다.
     - 끝에 0 µm를 한 번 더 쟀으면 `-70:70:10, 0`, 왕복이면 `-70:70:10, 60:-70:-10`.
   - **픽셀 크기**: FOV 보정 값 (기본 0.34278 µm/px)
   - **지점 A**: Die 좌표 X −120 mm (창의 "스테이지 X" 칸). 로그를 붙여 넣거나 **불러오기…**로 .txt/.csv를 고른다.
   - **지점 B**: Die 좌표 X +120 mm. 지점 A와 같은 방법으로 넣는다.
   - CSV도 받는다. 열은 `command_um, x_px, y_px[, angle, score]`이다.
4. **분석**을 누른다. 결과는 다음과 같이 나온다.
   - **판정 칩**: 정상 / 주의 / 초과(불합격) / **판정 보류**(8장 그럴듯함 검사) / 참고(X 대조·개루프)
   - **κ ± σ**
   - 지점별 이득·직각 기울기·잔차·최저 Score·빠진·뺀 단계 표
   - 그래프: 비전 변위 대 지시, 직선 맞춤 잔차
   - 판정 이유 (판정 보류면 그 이유가 맨 앞)
5. 대조 시험을 했으면 X 스윕도 분석한다.
   - 구동 축을 **X (대조)**로 바꾼다.
   - 지점 좌표(Die 좌표 Y −120 / +120 mm)와 X 스윕 로그를 넣고 분석한다.
   - X 결과는 Y 결과에 "대조"로 붙는다. X 스윕만으로는 판정하지 않는다.
6. 결과를 내보낸다.
   - **결과 복사**: 메일이나 보고서에 붙여 넣는다.
   - **CSV로 저장…**: 기록용 파일로 남긴다.
   - **진단에 추가**: 폐루프 **Y 스윕** 결과만 넣을 수 있다 (X 대조만·개루프 xlsx는 단추가 꺼진다).
     - 진단이 열려 있으면 "진단에 저장됨" — XY 진단 보고서(JSON `rotation_test`)에 바로 들어간다.
     - 아니면 "진단 실행 시 포함됩니다" — 다음에 진단을 실행할 때 들어간다.
7. 참고: PQC Non-linearity 분석 시트(xlsx)를 불러올 수도 있다.
   - **"또는 Non-linearity 분석 시트(xlsx) 불러오기"**를 쓴다.
   - 검출기 지점별 개루프 이득, Y1↔Y2·X1↔X2 이득 차(%), Det Stroke, 최저 Score가 나온다.
   - servo OFF 데이터이므로 판정하지 않는다. 가설 ④(Y1/Y2 상대 교정)의 참고값이다.
   - 검출기 지점 좌표를 넣으면 **개루프 비틀림**을 계산하지만 κ(폐루프 회전)로 쓰지 않는다.
   - 지점 좌표는 폐루프 시험 좌표와 따로 기억한다.

## 7. 계산

| 기호 | 정의 |
|---|---|
| 비전 변위 | 매칭 좌표(px) × 픽셀 크기. 방향은 Non-linearity 분석 시트와 같다: 스테이지 X = −화면 x, 스테이지 Y = +화면 y |
| 이득 g | 지점마다 구동 축 방향 비전 변위를 지시 µm에 직선 맞춤한 기울기 (최소제곱) |
| κ [µrad/µm] | (g_B − g_A) / L[mm] × 1000. L은 두 지점 사이 거리(B 좌표 − A 좌표)이다 |
| σκ | √(se_A² + se_B²) / \|L\| × 1000. se는 기울기 표준오차이며, σκ는 1σ이다 |
| 직각 기울기 | 직각 방향 비전 변위 / 지시 µm × 1000 (mrad). 카메라와 스캐너 축 사이의 정적 각도이며 **참고용**이다 |
| 선형 잔차 | 직선 맞춤 잔차의 p-p (µm). 비선형 % = p-p / (\|g\| × 유효 명령 폭) × 100. 유효 명령 폭은 계산에 쓴 명령의 최대 − 최소 (빠진 단계가 없으면 140 µm) |
| 맞춤 점 | 측정 없음·Score 미달 단계를 빼고, 두 지점에 **함께 있는 명령만** 쓴다 |
| 반복 측정 차 | 같은 명령을 두 번 이상 잰 축 방향 변위의 최대 − 최소 (드리프트 확인) |

**계산 예**:

- 240 mm 떨어진 두 지점의 이득이 1.0012와 1.0268이면 이득 차는 0.0256이다.
- κ = 0.0256 / 240 × 1000 = **0.107 µrad/µm** → 초과.

**부호**:

- Y 스윕에서 κ가 +이면, X가 큰 쪽 지점이 +Y로 더 많이 움직인 것이다 (스테이지 좌표에서 반시계 회전).
- A·B 이름을 바꿔도(A가 +120 mm) L = B − A라 κ는 같다.
- X 스윕(대조)은 L = Y_B − Y_A이고, 같은 반시계 회전이면 부호가 반대다.
- 판정은 |κ|로 한다.

## 8. 판정 기준 (잠정)

| 판정 | 조건 (µrad/µm) |
|---|---|
| 정상 (ok) | \|κ\| ≤ 0.07 |
| 주의 (warn) | 0.07 < \|κ\| ≤ 0.10 |
| 초과 (fail) | \|κ\| > 0.10 |

**근거**:

1. ±120 mm Die에서는 회전 θ(µrad)가 Range에 **θ × 0.24 µm**를 더한다 (240 mm × θ).
2. Range 규격 1.0 µm 중 **25 %(0.25 µm)를 회전에 배분**하면 θ ≤ 1.0 µrad이다 (주의 0.7 µrad).
3. 레시피 스캐너 오프셋을 **10 µm 이하**로 관리하면 κ ≤ 1.0 / 10 = **0.10**이다 (주의 0.07).

**확정 계획**:

- 출하 검사와 정비 후 데이터를 모은다.
- 장비별 κ의 **평균 + 3σ**로 규격을 확정한다.
- 그때까지 분석 창과 보고서에는 "잠정 규격"이라고 표시한다.
- 규격 값은 설정 `rotation_spec`으로 바꿀 수 있다.

**판정 대상**: 폐루프 **Y 스윕**만 판정한다. X 스윕(대조)과 개루프 xlsx는 참고값이다.

**그럴듯함 검사 (판정 보류)**: 아래 중 하나라도 걸리면 판정하지 않고 "판정 보류"로 보인다.
이유는 판정 이유 맨 앞에 `[판정 보류]`로 나온다. 원인을 고쳐 다시 잰다.

| 검사 | 기준 (설정 `rotation_test_gate`) | 흔한 원인 |
|---|---|---|
| 이득 ≤ 0 | — | 구동 축을 잘못 고름, 명령 순서가 뒤집힘 |
| \|평균 이득 − 1\| | > 0.10 (`gain_tol`) | 구동 축 잘못 고름, servo OFF, 명령 대신 줄 번호, 픽셀 크기 틀림 |
| 지점별 잔차 p-p | > 0.5 µm (`residual_pp_max_um`) | 다시 잰 줄·빠진 줄로 단계가 밀림, 잘못된 매칭 |
| 지점별 비선형 | > 2 % (`nonlinearity_max_pct`) | 위와 같음 |
| \|g_B − g_A\| | > 0.2 (`gain_diff_max`) | 두 로그가 다른 시험 (축·명령·서보) |
| 두 지점 거리 \|L\| | < 50 mm (`min_distance_mm`) | 좌표 입력 잘못, 가까운 Die에서 잼 |

개루프 xlsx에는 이득 ≤ 0·이득 차·거리 검사만 쓴다 (개루프 이득은 1.2~1.3이고 잔차가 크다).

**재측정**:

- κ ± 2σ가 0.07이나 0.10 경계에 걸치면 분석 창이 "다시 재서 확인"을 표시한다.
- 반복 측정 차가 0.2 µm(`drift_max_um`)를 넘으면 드리프트를 경고한다.
- 그 경우 한 번 더 측정한다.

## 9. 이상 시 조치 (주의·초과)

다음 순서로 원인 범위를 좁힌다.

1. **DB를 확인한다.**
   - Y / YAux 검출기 **MicrometerPerAdc** 값과 그 비(Y2/Y1)를 확인한다.
   - **bUseDualServo** 설정을 확인한다.
   - **rotation feedback gain** 값을 확인한다.
   - 같은 모델의 정상 장비와 비교한다.
2. **Linearization을 다시 한다** (WI-XY Scanner-01).
   - **Vision spot을 검출기 위치에** 맞춘 상태에서 한다.
   - 그 뒤 이 시험을 다시 한다.
3. **2-게이지 시험으로 원인을 가린다.**
   - **척 좌·우**에 게이지 2개를 대고 Y 스윕을 한다. 두 게이지의 차이가 척에서 본 회전이다.
   - 같은 시험을 **스캐너 상판**(척 아래)에서 되풀이한다.
   - 결과에 따라 원인을 아래 표처럼 가린다.

   | 관찰 | 의심 원인 |
   |---|---|
   | 척에서만 크고 상판에서는 작다 | ③ **척 체결** (체결 토크·안착면) |
   | 상판에서도 같다 | 스캐너 본체의 문제다. 아래 두 줄로 더 가린다 |
   | └ 상판 회전이 Y1·Y2 검출기 차이에 보이는데 서보가 바로잡지 못한다 | ④ **Y1/Y2 상대 교정**·Dual servo 설정 |
   | └ 검출기에는 보이지 않는다 | ① **PZT 밀기 선**(push line) 정렬 또는 ② **힌지**(flexure) |

4. **본사(Park)에 에스컬레이션한다.** 1~3으로 해결되지 않으면 다음 자료를 첨부한다.
   - 분석 창 CSV
   - 복사한 결과
   - 2-게이지 결과
   - DB 값

## 11. WI-XY Scanner-01 개정 제안

1. **스윕마다 4개 검출기 채널(X1, X2, Y1, Y2)을 모두 기록한다.**
   - 지금은 시트마다 해당 채널(예: Y1 시트는 Y1 Detector) 하나만 남는다.
   - 4채널을 함께 남기면 개루프에서도 다음을 바로 볼 수 있다.
     - Y 구동 중 Y1−Y2 차이 (= 검출기가 본 회전)
     - X 채널의 결합
   - 그러면 가설 ④(Y1/Y2 상대 교정)를 따로 시험하지 않고 확인할 수 있다.
   - 참고 (현재 시트, After): Y1 지점 개루프 이득 1.19, Y2 지점 1.33 (+11 %)이다.
     Det Stroke 비 Y2/Y1도 1.111로 같은 크기다.
2. **회전 확인을 추가한다.**
   - Linearization After 확인 뒤, 이 문서 5.1의 Y 스윕(servo ON, Die 좌표 X ±120 mm)을 한다.
   - κ를 Non-linearity 시험 기록에 함께 남긴다.
3. **로그 규칙을 맞춘다.** GRAB and RUN 한 번에 `Match 1` 한 줄, 재시도는 이전 줄 삭제
   (또는 줄 앞에 명령 값), 소수점은 마침표 — 이 문서 5.3과 같게.
4. 분석 시트의 "log" 시트에 개정 이력을 남긴다.
   - 4채널 기록 열과 회전 시험 결과 칸을 추가한다.
